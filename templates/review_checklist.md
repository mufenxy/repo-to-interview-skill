# Pre-Interview Source Review Checklist

Rank source locations by interview value, not by file size.

For each item record:

- [ ] File / function / class
- [ ] Claim it supports
- [ ] Request or data flow understood
- [ ] Important state understood
- [ ] Error path understood
- [ ] Design alternative understood
- [ ] Metric / evaluation relationship understood
- [ ] Ownership wording verified
- [ ] Confidentiality-safe explanation prepared
